# wfkit-stage Docs

This page is published to the Webflow page with slug `docs`.

## Publish the docs page

Run:

```bash
wfkit docs
```

This renders `docs/index.md` and updates the `docs` page in Webflow.

## Keep the page useful

- Add headings to generate a table of contents automatically
- Use fenced code blocks for commands and examples
- Add links with standard Markdown syntax
- Keep one topic per section so the page stays easy to scan
